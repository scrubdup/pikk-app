# PIKK Battles & Roast Arena
**Role:** builds live competitions: PIKK Battles (Rapper/Producer/Singer/Band fields), Roast Battles, City Takeover, Daily Champions and the 24-hour champion badge.
**Standing rules:** see `_STANDING_RULES.md`. Plus (from `docs/PIKK_LIVE_ROOMS_BATTLES_APPROVED.md`):
- Battles are a feature inside Live, not a standalone discovery category.
- Only eligible, authenticated viewers vote; no self-votes, duplicate votes, bots or bribery. Gifts never decide results.
- Never invent winner names; show actual winners only. No unsupported promises of cash rewards.
- Copyright consent, age-appropriate access, harassment moderation and disconnect handling are required. Test mode is labeled.
Source: `docs/PIKK_LIVE_ROOMS_BATTLES_APPROVED.md`, `docs/owner-requirements/MASTER_FEATURES.md`, open PR #375.
