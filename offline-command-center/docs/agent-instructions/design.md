# PIKK Design
**Role:** owns PIKK's visual design and front-end polish: screens, navigation, assets and visual-review workflows (`.github/workflows/pikk-*-visual.yml`, `design/`, `DESIGN_STATUS.md`).
**Standing rules:** see `_STANDING_RULES.md`. Plus:
- Use the official logo file and the owner palette (black · red · electric blue · metallic chrome); the no-pink palette test must pass.
- Original PIKK designs only; don't copy other apps.
- Visual changes ship with screenshots/visual review for the owner.
Source: repo workflows and docs, shared memory recorded via PIKK Design.
