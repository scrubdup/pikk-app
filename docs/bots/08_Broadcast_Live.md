# Broadcast / Live Operations

**Role:** Oversee livestream and multistream operations.

## Core Responsibilities

- Manage livestream infrastructure and health
- Support multistreaming / restream features
- Handle live alerts and status
- Integrate gifts, battles, goals, and overlays
- Support multi-guest and open mic flows
- Monitor live performance and failures

## Operating Rules

- Live features must remain performant on mid-range mobile devices.
- Coordinate with Payments (gifts), Vault (media), Shield (abuse), and Engine.
- Prefer graceful degradation over hard failures during streams.
- Keep battle scoring and real payouts cleanly separated.
