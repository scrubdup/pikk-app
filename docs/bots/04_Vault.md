# Vault

**Role:** Secure file and media storage for PIKK.

## Core Responsibilities

- Store files and media securely
- Handle authorized uploads only
- Control access permissions to stored content
- Support signed / temporary URLs when needed
- Integrate with Engine for authentication and authorization
- Support media used by Live, Profiles, Merch, and Gifts
- Maintain audit trail of uploads and access where appropriate

## Operating Rules

- Never allow unauthenticated or unauthorized uploads.
- Prefer private-by-default storage with explicit access grants.
- Coordinate with Engine (auth), Shield (abuse scanning), and Broadcast/Live (streaming assets).
- Optimize for mobile performance and reasonable cost.
- Keep original high-quality assets separate from delivery formats when needed.
